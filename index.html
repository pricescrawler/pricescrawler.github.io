Open-source framework · Reactive Spring Boot · MIT

Compare prices from any store. Write only the parser.

content-base is a Java framework for building price APIs. Caching, price history, product lists, failure detection and the REST API come built in. Each store is one class.

What happens on every search

BaseProductService
frameworkCatalog active?Disabled stores answer empty without touching the site.
frameworkCacheMongoDB or in-memory, per locale, catalog and query.
your codeStore parserSearch by query, by URL, and refresh list items.
frameworkNormalized pricesRegular, campaign and unit price as numbers.
frameworkHistorySaved in the background on every live search.
frameworkMetrics and errorsFailures become empty results and a broken-parser signal.

Add a store in 3 steps

start from content-api-example
1
Add the dependency 
<dependency>
  <groupId>io.github.pricescrawler.content</groupId>
  <artifactId>prices-crawler-content-controller</artifactId>
</dependency>
2
Write one class per store 
@Service
@Qualifier("pt.mystore")
public class MyStoreProductService extends BaseProductService {
    protected Mono<SearchProductsDto> searchItemLogic(FilterProductByQueryDto f) { … }
    protected Mono<SearchProductDto> searchItemByProductUrlLogic(FilterProductByUrlDto f) { … }
    protected Mono<ProductListItemDto> updateItemLogic(ProductListItemDto item) { … }
}
3
Register the catalog

Add a locale and a catalog document in MongoDB with the same key, pt.mystore. The store then shows up in the web app and the mobile app, and you can switch it on or off without a deploy.
